## Frequently Asked Questions

### Does Shuowen require an internet connection?

No. Browse, search, favorites, roam, and entry detail all work offline. The dictionary database is bundled with the App.

### Why is the database empty after building from source?

The repository does not ship full dictionary JSON. Follow the README to import entries and build `shuowen.store` before running the App.

### Is Shuowen affiliated with shuowen.org?

No. Shuowen is an independent open-source client. Dictionary data is derived from the [shuowenjiezi/shuowen](https://github.com/shuowenjiezi/shuowen) project under Apache 2.0.

### Where can I see third-party licenses?

In the App: **Settings → Acknowledgments → Open Source Licenses**.

On the web: see the [GitHub repository](https://github.com/qiyangdev/Shuowen) README and `ThirdPartyNotices.txt`.
